# codealpha_tasks

A collection of web development projects completed as part of my **CodeAlpha Web Development Internship**.

This repository contains multiple frontend projects built using **HTML5, CSS3, and JavaScript**, with a focus on responsive design, user experience, and practical JavaScript functionality.

---

## 📂 Projects

### 🖼️ 1. Image Gallery

A modern and responsive image gallery featuring category filtering, image previews, navigation controls, and a clean lightbox experience.

**Key Features:**
- Responsive image grid
- Category filtering
- Lightbox / image preview
- Previous & Next navigation
- Keyboard navigation
- Image counter
- Hover effects
- Mobile responsive design
- Accessible interface

**Technologies:**
- HTML5
- CSS3
- JavaScript

📁 **Project Folder:** [`ImageGallery`](./ImageGallery)

🔗 **Live Demo:** [View Image Gallery](#)

---

### 🎵 2. VibeWave — Music Player

A modern music player interface inspired by contemporary music streaming platforms, built with vanilla JavaScript and the HTML5 Audio API.

**Key Features:**
- Play / Pause
- Previous / Next track
- Progress bar and seeking
- Volume control
- Mute functionality
- Shuffle mode
- Repeat mode
- Autoplay
- Search functionality
- Favorites using LocalStorage
- Up Next queue
- Responsive design
- Keyboard controls

**Featured Tracks:**
- 🎵 Heaven on the Earth
- ☁️ In the Clouds
- Midnight Drive
- Lost in Tokyo
- Afterglow
- Ocean Escape
- Night Runner
- Golden Horizon

**Technologies:**
- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- LocalStorage

📁 **Project Folder:** [`MusicPlayer`](./MusicPlayer)

🔗 **Live Demo:** [View Music Player](#)
